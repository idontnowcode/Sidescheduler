# Fantasy Reference Kit v1

최종 목표 화면을 재현하기 위한 LightNote 판타지 UI 에셋 제작 명세.

- 대상 폴더: `design/theme-assets/raw/fantasy-reference-kit-v1/`
- 최종 목표: `codex-clipboard-1e83e722-a306-4deb-acba-8fea4fbee6dc.png`
- 생성 방식: 내장 이미지 생성 → 규격화/알파 정리 → 접촉 시트 검사
- 에셋에는 글자를 넣지 않는다. 모든 문구와 숫자는 앱에서 렌더링한다.

## 1. 공통 시각 규칙

1. 기본 재질은 거의 검정인 균열 석재와 무광 흑철이다.
2. 금속 하이라이트는 밝은 노란 금색이 아니라 산화된 청동색이다.
3. 적색은 선택 상태와 하단 상태바에만 사용한다.
4. 프레임 중앙은 콘텐츠를 방해하지 않도록 저대비여야 한다.
5. 9-slice용 프레임은 모서리 장식과 중앙 늘림 영역이 명확해야 한다.
6. 투명 PNG의 외곽에는 적색·녹색 색수차가 없어야 한다.
7. 광택, 주황색 발광, 과도한 가시 장식, 보석 남용을 금지한다.
8. 작은 아이콘은 28px에서도 실루엣이 구분되어야 한다.

아이콘 프롬프트 핵심:

> 4×4 정렬 아이콘 판. 모든 아이콘은 동일한 크기와 조명, 가는 청동 외곽선과 낮은 금속 양각, 내부는 대부분 비움. 작은 크기에서 읽히는 단순 실루엣. 글자·숫자·배경 장식 없음.

상태 규칙:

- `star-off`: 속이 빈 가는 청동 외곽선 별. 배경과 발광 없음.
- `star-on`: 동일한 실루엣을 유지하되 내부가 따뜻한 낡은 금색으로 채워짐. 아주 약한 하이라이트만 허용.
- `check-off/on`, `pin-off/on`: 전후 상태에서 외곽 크기와 중심 위치가 완전히 같아야 한다.
- 선택 행의 붉은 배경은 아이콘에 굽지 않고 `row-active.png`가 담당한다.

## 5. 후처리 규칙

1. 모든 파일을 표의 최종 규격으로 맞춘다.
2. 투명 에셋은 알파 외곽의 적·녹색 색수차를 제거한다.
3. 검정 배경으로 생성된 아이콘 판은 밝기를 알파로 변환한다.
4. 아이콘은 셀 안쪽 8px를 제외하고 탐색해 개별 128×128로 자른다.
5. 9-slice 에셋의 slice 값은 자동 측정 후 `manifest.json`에 기록한다.
6. 접촉 시트를 만들어 검정 배경과 중성 회색 배경에서 모두 검사한다.

## 6. 합격 기준

- 프레임 네 변의 두께가 시각적으로 일정하다.
- 중앙 stretch 영역에 큰 장식이나 균열의 중심점이 없다.
- 적색은 선택 명판과 상태바 외에는 나타나지 않는다.
- 모든 빈 에셋에는 글자·아이콘·숫자가 없다.
- 아이콘 16개가 각각 한 셀 안에 완전히 들어간다.
- 28px 아이콘 미리보기에서 형태를 식별할 수 있다.
- 패널 질감 위에서 본문 텍스트 대비가 유지된다.
- 종이 장식이 본문 안전 여백을 침범하지 않는다.
