# 시안을 "복사 수준"으로 옮기기 — 무엇이 되고 무엇이 안 되나

## 1. 질문에 먼저 답하면

물어보신 것 **전부 됩니다.** 그리고 질감 이미지보다 **쉬운** 쪽입니다.

| 물어보신 것 | 되나 | 어떻게 |
|---|---|---|
| 앱 타이틀 글씨체 | 됨 | 세리프 웹폰트를 앱에 넣음. 테마마다 다른 글꼴·색·자간 가능 |
| 고른 항목 배경색 바뀜 | 됨 | 이미 그렇게 동작 중. 색만 테마 값으로 바꾸면 됨 |
| 좌측 버튼 누를 때 금테 | 됨 | `border-left` / `box-shadow: inset`. 두께·색·길이까지 테마별로 |
| 폴더 모양 탭 | 됨 | `clip-path` + 둥근 모서리 |
| 종이 줄·모눈·빨간 여백선 | 됨 | CSS 그라데이션. 이미지보다 선명하고 테마 색을 따름 |
| 상태바 와인색 띠 | 됨 | 색 하나 |
| 아래 눈금자(시안 2) | 됨 | SVG |

**세 테마 모두** 됩니다. 색뿐 아니라 **구조**까지 테마마다 다르게 둘 수 있습니다
— 실제로 시안 셋은 구조가 다릅니다(아래 3번).

### 1:1이 안 되는 것 둘 — 미리 말씀드립니다

1. **로고 글자 모양.** 시안의 "LightNote"는 **진짜 글꼴이 아닙니다.** 이미지
   생성기가 글자처럼 **그린** 것이라, 그 글꼴을 찾아서 넣는 게 불가능합니다.
   비슷한 분위기(세리프·약간 좁은·따뜻한)의 실제 글꼴로 맞추고, 후보 3~4개를
   같은 크기로 나란히 찍어 드릴 테니 고르시면 됩니다. 글자 모양만 빼면 색·
   크기·자간은 똑같이 맞춥니다.
2. **질감의 '그 무늬'.** 가죽 결 하나하나가 같을 수는 없습니다. 같은 재질·같은
   거칠기까지는 맞춥니다.

나머지는 **픽셀 색을 시안에서 직접 뽑아 씁니다.** 아래 4번이 그 결과입니다.

---

## 2. 그러려면 테마 체계를 늘려야 합니다

지금 테마는 **색 7개**(`--bg --bg2 --bg3 --bg4 --border --text --text-dim`)만
바꿉니다. 고른 줄의 바탕색, 금테, 종이, 탭 모양, 상태바, 로고 글꼴 같은 건
토큰이 없어서 **CSS 안에 박혀** 있습니다.

이대로 시안 셋을 넣으면 테마마다 "이 테마일 때만" 덮어쓰는 CSS 덩어리가 셋
생깁니다. 그렇게 하면:

- 어느 규칙이 이기는지(특이도) 싸움이 시작되고,
- 화면을 하나 고칠 때마다 세 군데를 같이 고쳐야 하고,
- 빠뜨린 한 군데가 다른 테마에서만 깨집니다.

그래서 **토큰을 약 26개로 늘리고, 화면 CSS는 토큰만 읽게** 합니다. 테마는 값
목록 하나가 됩니다. 새 테마를 넣는 일도 값 한 벌 추가로 끝납니다.

---

## 3. 시안 셋은 색만 다른 게 아닙니다

픽셀을 떠 보고 알게 된 것 — **가운데 페이지 목록 칸과 오른쪽 패널의 밝기가
테마마다 다릅니다.**

| | 레일·사이드바·헤더 | 가운데 목록 칸 | 오른쪽 패널 |
|---|---|---|---|
| 가죽 서재 | 검정 가죽 | **어두움** | 어두움 |
| 현장 노트 | 네이비 천 | **크림(밝음)** | 크림 |
| 고서재 | 짙은 초록 천 | **양피지(밝음)** | 양피지 |

그래서 "사이드바 색"과 "목록 칸 색"은 **다른 토큰**이어야 합니다. 지금은 둘 다
`--bg2`를 씁니다. 이걸 안 갈라 두면 현장 노트·고서재에서 가운데 칸이 네이비/
초록으로 나와 시안과 달라집니다.

---

## 4. 시안에서 뽑은 색 (초안)

세 PNG에서 자리별로 **가장 많이 쓰인 색**을 떠낸 값입니다. 구현할 때 더 좁은
칸으로 다시 떠서 다듬습니다.

| 토큰 | 쓰임 | 가죽 서재 | 현장 노트 | 고서재 |
|---|---|---|---|---|
| `--chrome-bg` | 사이드바·헤더 | `#161514` | `#152c42` | `#243224` |
| `--rail-bg` | 맨 왼쪽 버튼 바 | `#151413` | `#14293e` | `#1d2a1e` |
| `--list-bg` | 가운데 목록 칸 | `#1c1b1a` | `#e5e2da` | `#ded1ba` |
| `--panel-bg` | 오른쪽 패널 | `#1c1c1a` | `#dedad3` | `#e6dac4` |
| `--sel-bg` | 고른 줄 바탕 | `#4b161b` | `#e96a23` | `#e3d4bb` |
| `--rail-active-bg` | 눌린 레일 단추 | `#45151a` | `#e8590c`※ | `#c9a227`※ |
| `--tabbar-bg` | 탭 줄 바탕 | `#1c1c1a` | `#cdcac4` | `#cdba9c` |
| `--tab-active-bg` | 켜진 탭 | `#3c1a1a` | `#e3ded4` | `#ebdbc4` |
| `--paper-bg` | 본문 종이 | `#ede3d6` | `#e6e2d9` | `#eee1cb` |

(`#2a6c82`)입니다. 금색 테마인데 거기만 원본 스크린샷의 파란색이 남은 것으로
보입니다. 그대로 베끼면 그 칸만 떠 보여서, **금색으로** 맞추겠습니다. 시안
그대로가 좋으시면 말씀해 주세요. 시안 2의 눌린 단추도 같은 이유로 주황으로
정리했습니다.

## 5. 늘릴 토큰 (26개)

| 묶음 | 토큰 |
|---|---|
| 바탕 | `--bg` `--chrome-bg` `--rail-bg` `--list-bg` `--panel-bg` `--hover-bg` `--border` |
| 글자 | `--text` `--text-dim` `--text-on-sel` |
| 고름 | `--sel-bg` `--sel-edge` `--sel-edge-w` `--rail-active-bg` `--rail-active-fg` |
| 종이 | `--paper-bg` `--paper-ink` `--paper-rule` `--paper-margin` `--paper-shadow` |
| 탭 | `--tab-bg` `--tab-active-bg` `--tab-shape` |
| 띠 | `--status-bg` `--status-fg` |
| 로고 | `--logo-font` `--logo-ink` `--logo-tracking` |
| 질감 | `--tex-chrome` `--tex-chrome-opacity` `--tex-paper` `--grain-opacity` |
| 강조 | `--accent` `--accent-hover` `--danger` `--edge-gold` |

기존 다섯 테마(Dark·Light·Sepia·OLED·Forest)는 **그대로 둡니다** — 새 토큰에
지금 모습과 같은 기본값을 주면 보이는 게 안 바뀝니다.

---

## 6. 순서

질감 이미지를 기다리는 동안 **1·2번은 먼저 할 수 있습니다.**

1. 토큰 26개로 늘리고 화면 CSS가 토큰만 읽게 정리 (보이는 건 안 바뀜)
2. 세 테마 값 넣기 — 색·금테·선택 바탕·상태바·폴더 탭·종이 줄까지 (질감 없이)
3. 로고 글꼴 후보 3~4개 나란히 찍어 드리기 → 고르시면 적용
4. 질감 4장 도착 → 이음새 확인 → 얹기
5. 세 테마 × 창 크기별 캡처로 시안과 나란히 비교

먼저 1·2를 해 둘까요? 질감 없이도 색·금테·탭 모양까지는 시안에 꽤 가깝게
나옵니다. 그 상태로 보시고 어긋난 데를 짚어 주시면 그때 다듬는 쪽이, 다 만든
뒤 한꺼번에 고치는 것보다 빠릅니다.
