# LightNote 업무 진행 현황 보고서 Export — 설계

## 목적

각 업무 페이지에 흩어져 있는 업무 속성을, 종합 진행 현황 보고를 위한
기반 자료(초안)로 한 번에 뽑아낸다. 뽑은 결과물은 Copilot으로 다듬어
Word 문서로 완성하는 것이 최종 목적 — 따라서 완성된 보고서가 아니라
"정리된 재료"를 만드는 게 이 기능의 역할이다.

## 원칙: 업무 속성 vs 페이지 내용

- **업무 속성** = 정제된 내용, export에 노출됨 (기존 상태·기한·액션·
  결정사항과 동일한 성격)
- **페이지 본문** = 메모/정제 전 내용, export에 노출되지 않음

이번에 추가하는 필드도 전부 "업무 속성"에 속한다.

## 새 필드 4종 (WorkObject)

| 필드 | 타입 | 성격 | Export 노출 |
|---|---|---|---|
| `background` | `string` | 업무 배경 (자유 텍스트) | 있으면 노출 |
| `purpose` | `string` | 업무 목적 (자유 텍스트) | 있으면 노출 |
| `progressLog` | `{id, at, text}[]` | 진행 현황 — 기존 `decisions`(결정사항 이력)과 동일 구조, 날짜별 누적 | **전체** 이력 노출 |
| `pendingDecisions` | `{id, text, raisedAt, resolved, resolvedAt}[]` | 의사결정 필요사항 — 체크리스트. 해결해도 패널에서 안 지워지고 취소선으로 남음 | **미해결(`resolved:false`)만** 노출 |

기존 `nextActions`(다음 Action)는 새 필드 아님 — export 시 `!done`인
것만 필터링해서 재사용.

기존 `decisions`(결정사항 이력)는 이번 export 목록에 **포함하지
않음**(내부 참고용 그대로 유지).

## 패널 UI

기존 패널이 이미 빽빽하므로, 새 4개 필드는 **"📋 보고용 정리"라는
접이식 서브섹션**으로 분리한다(기본 접힘). 배경/목적은 텍스트박스,
진행현황은 결정사항과 같은 로그 UI, 의사결정 필요사항은 다음 Action과
같은 체크리스트 UI 패턴을 재사용한다.

## 업무 현황 탭 — 내보내기 트리거

**업무 모드** 표에 체크박스 열 추가. 1개 이상 선택 시 헤더에
"📤 선택 항목 내보내기 (N)" 버튼 노출 → 저장 대화상자로 파일 하나
생성(선택한 여러 업무를 하나의 문서로 통합).

## 출력 형식 — 개조식 (Markdown `#` 헤더 사용 안 함)

Markdown `#` 헤더는 "AI가 정리한 느낌"이 강하다는 피드백에 따라,
한글 보고서에서 흔히 쓰는 **번호-문자 개조식**(`1.` → `a.` → `-`)의
평문으로 출력한다. 파일 확장자는 `.md`로 유지(Copilot/Word에 텍스트
그대로 붙여넣기 좋음) — 내용 자체는 마크다운 문법을 쓰지 않는다.

```
업무 진행 현황 보고서
생성일: 2026-08-13

1. 신규 대시보드 API 연동
    a. 목표 기한: 2026-08-14
    b. 배경
       대시보드 위젯에 필요한 집계 API를 신규로 설계·연동한다.
    c. 목적
       실시간 지표 조회 속도 개선.
    d. 진행 현황
       - 2026-08-10: 인증 토큰 발급 플로우 확정
       - 2026-08-12: 집계 엔드포인트 스키마 리뷰 완료
    e. Action Item (미완료)
       - 에러 응답 케이스 정의
       - QA 시나리오 작성
    f. 의사결정 필요 사항
       - 캐시 TTL 1시간 vs 30분 결정 필요

2. 월간 보고서 취합
    a. 목표 기한: 2026-08-11
    ...
```

- 상태/우선순위는 **넣지 않음**(사용자 명시적 제외).
- 목표 기한은 넣음.
- **내용이 없는 필드는 통째로 생략**하고, 문자(a/b/c…)는 실제 출력된
  항목 순서대로 다시 매긴다(빈 칸으로 인한 문자 건너뜀 방지 — 예:
  배경이 없으면 b가 아니라 c부터 시작하는 식의 어색함을 없앰).
- 업무 사이는 빈 줄로 구분.

## AI 사용 여부

100% AI-free. 순수 필드 조합/포매팅이며 어떤 코드 경로도 AI API를
호출하지 않는다 — 기존 업무 객체 기능의 원칙과 동일.
